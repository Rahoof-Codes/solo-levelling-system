# Solo Leveling — Workout Exercise GIFs Directory

Place your `.gif` animation files in this directory (`public/workouts/gifs/`).
The Guided Workout screen automatically detects and renders the matching GIF based on the current exercise!

If a `.gif` is not found, the app automatically falls back to `/exercise-demo.png`.

---

## Workout Protocols List
1. **Push Day — Upper Press** (Chest, Triceps, Anterior Deltoids)
2. **Pull Day — Back & Grip** (Lats, Traps, Rhomboids, Biceps)
3. **Leg Day — Lower Power** (Quads, Hamstrings, Glutes, Calves)
4. **Full Body — Total Combat** (Compound Movements, Kinetic Chain)
5. **HIIT — Shadow Speed** (High-Intensity Intervals, Anaerobic Capacity)
6. **Core — Unbreakable Guard** (Rectus Abdominis, Obliques, Transverse)
7. **Rest Day — Active Recovery** (Mobility, Restoration, Parasympathetic)
